# India MCP Demo

## Components
- Spring Boot API
- MCP Server (Node.js)
- CLI Client

## Run Steps

### 1. Start Spring Boot
mvn spring-boot:run

### 2. Start MCP Server
cd mcp-server
npm install
node server.js

### 3. Run Client
cd client
npm install
node client.js

## Example
Input:
What is the capital of Rajasthan?

Output:
Capital of Rajasthan is Jaipur
